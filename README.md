# Retinal Disease Detection

> A modular Deep Learning framework for retinal disease classification using fundus images.

---

## Overview

Retinal Disease Detection is a Computer Vision and Deep Learning project focused on automatic classification of retinal diseases from fundus photographs.

The primary goal of this project is not only to build a high-performing classifier, but also to develop a production-quality, modular ML pipeline following software engineering best practices.

---

## Objectives

- Build a modular Deep Learning system.
- Compare multiple CNN and Transformer architectures.
- Create a fully reproducible experiment pipeline.
- Follow MLOps-oriented engineering practices.
- Produce a portfolio-quality project.
