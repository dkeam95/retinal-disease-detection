# Notebooks Directory (`notebooks/`)

Jupyter notebooks and exploratory data analysis (EDA) scripts.

## 📌 Overview

This directory contains research notebooks used for initial data exploration, class distribution auditing, image resolution inspection, and channel brightness profiling across retinal fundus images.

---

## 🗂️ Files

* **`eda.ipynb`**: Interactive Jupyter Notebook performing EDA on Diabetic Retinopathy dataset.
* **`eda_full.py`**: Standalone Python script reproducing full EDA analysis programmatically.
* **`run_eda.py`**: CLI script for executing EDA and saving generated figures to `reports/eda/`.

---

## 💻 Running EDA

```bash
python notebooks/run_eda.py
```
