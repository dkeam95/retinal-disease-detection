# Reports Directory (`reports/`)

Generated plots, EDA graphics, error analysis audits, evaluation metrics, and final PDF summary reports.

## 📌 Overview

This directory acts as the central output location for generated figures, analytical summaries, diagnostic plots, and clinical reports produced by the Retinal Disease Detection pipeline.

---

## 🗂️ Directory Structure

```
reports/
├── eda/                                     # Exploratory Data Analysis figures (class distribution, resolution, etc.)
├── error_analysis/                          # Misclassification analysis, confusion matrices, and audit JSONs
├── figures/                                 # Training history curves, ROC/PR curves, and Grad-CAM saliency heatmaps
├── benchmarks/                              # Multi-model comparative benchmark CSVs and tables
└── retinal_disease_detection_final_report.pdf # Consolidated executive summary PDF report
```
